对照来源：`MrCroxx/olanzi`，2026-11-02 拉取的提交
`eb78f88f973d4d28f1d6d3369cdfb65881b1e1c6`。
检查了 README、`docs/images` 中列出的界面截图、原型 Web 样式，
以及当前原生界面的 `ContentView.swift`、`ActionPalette.swift`、
`ActionEditor.swift`、`Theme.swift`。
早期实现依据配色、布局和组件源码，后续已通过真实浏览器截图做视觉复核。

[Work Louder Input](https://worklouder.cc/input) 的设备配置思路。

## 仍有差异的能力

- **平台外壳**：Olanzi 当前主应用是 macOS SwiftUI；本项目是 Ubuntu 用户后台
  与本地网页，不提供相同的菜单栏、Dock 或 macOS 原生应用选择器。
- **APP 聚焦**：X11 使用可选 `wmctrl` 与窗口类匹配，安装包声明依赖；
  源码模式缺少 `wmctrl` 时启动应用。应用列表优先使用 `gtk-launch`，
  支持应用自身的 D-Bus 激活。Wayland 窗口聚焦受桌面协议约束，
  不保证与 macOS 相同的前台窗口行为。首次启动应用的宏应显式添加等待步骤。
- **按住输出**：仅在物理按键的单击槽支持保持按住，不能与同控件双击/长按共存；
  不支持在旋转脉冲或宏中保持按住，避免没有明确释放边界。
- **层继承**：`▽` 按层编号向下查找同一手势；缺省手势与显式 `×` 不自动继承。
  继承到按住/语音/临时切层动作时，该控件按独占单击动作处理。
- **QMK 代码**：只解析列明的语句子集，不运行任意 C/JavaScript；本项目
  `VIBEKEY_ACTION` 扩展与 Olanzi 的 `OLANZI_APP` 并非互换语法。
- **键盘与手势**：不实现 Mac Fn。快捷键录制受浏览器和桌面快捷键拦截影响。
  对录制超时、错误和权限提示等少数文案，当前仍可能显示中文或后台英文。
- **灯光与亮度**：三种模式和全亮亮度 0–20 档已通过 AU05 实机写入、回读及恢复验证；工作模式的状态颜色、呼吸效果尚未接入。
- **电量**：每 20 秒主动查询，并支持手动刷新；不发送 Studio 心跳。
- **场景预设**：AU05-X 默认、快速派活、多任务，以及 Codex CLI / Claude Code 两套独立方案，可保留当前语音键。
- **软件自动跟随**：X11 前台窗口匹配、默认方案回退、规则顺序和逐应用层设置；CLI 可通过固定窗口标识稳定区分。详见 [使用说明](auto-follow.md)。

## 验证

- Python 测试覆盖重复与取消、共享修饰键所有权、按住释放、断开/取消清理、
  显式继承、应用发现和窗口类匹配。
- Node 测试覆盖库更新传播、键盘录制转换、宏 Code 往返及无效代码拒绝。
- Chrome 集成检查实际操作手势卡片、表单、录制器、APP/宏库、宏重排/Code、
  图层、保存/重载、语言切换、SSE 和旋转计数。
- 桌面与窄屏检查覆盖键位、语音、设置，渲染预览输出至
  `dist/previews/workspace-desktop.png` 与 `workspace-mobile.png`。
- 保留此前实物采集的六控件映射；本轮不自动执行快捷键、聚焦窗口或录音。


## 设备图与配置框对齐

`web/workbench.css` 使用统一的 `--device-height`，设备本身按原图 188:692 等比显示，不再使用独立缩放和负外边距。上、中、下键的透明点击区和右侧手势矩阵共享中心坐标；旋钮矩阵与旋钮中心对齐。矩阵固定高度，长动作名通过两行截断及完整提示展示，避免撑开布局。

浏览器检查覆盖 1450、1280、1000、760、600、430、390、340 px 八个宽度：四组控件/矩阵中心偏差均小于 1.5 px，三键矩阵互不重叠，没有横向溢出。另检查桌面和手机截图，保留预设切换、自动跟随与动作编辑的原有交互。
