# 软件自动跟随

设置 → 软件自动跟随：启用后，设备按当前前台窗口使用对应方案；未绑定的应用使用选定的默认方案和默认层。可绑定任何已有方案。每条规则可指定方案、层、窗口类别、标题包含和固定窗口标识；填写的条件同时满足才匹配，多条匹配时使用最前一条。支持调整顺序和删除规则。

点击「刷新应用窗口」，选择窗口后「绑定所选窗口」，会自动填写窗口类别和窗口标识。需要区分同一个应用的不同窗口时，再填写「标题包含」。匹配不区分大小写；类别匹配完整的 WM_CLASS 或其组成部分，不执行正则表达式、Shell 或用户脚本。三种条件至少填写一项。

未匹配、桌面获得焦点或探测失败时使用默认方案。当前支持 X11 + xprop；Wayland 下显示不可用，不声称能读取全桌面窗口。

首页「场景预设」显示默认回退方案和五套场景模板，实际使用中的方案会高亮。点击卡片会保存并启用所选方案；尚未添加的模板会自动添加，并按“沿用当前方案的语音键”设置保留语音绑定。手动选择场景时关闭自动跟随，避免被自动规则立即切回。首页也可直接开关跟随，或点击「详细设置」跳转到完整规则配置。设置页的跟随开关作为草稿保存，首页开关直接保存生效。

## Codex CLI / Claude Code

场景预设新增两个独立方案。它们与 WorkBuddy 一样覆盖语音、发送确认和取消，并根据 CLI 提供不同的旋钮操作。

| 控件 | Codex CLI | Claude Code |
|---|---|---|
| 上键 | 按住语音（默认 RIGHTALT） | 按住语音（默认 RIGHTALT） |
| 中键 | Enter，发送 / 确认 | Enter，发送 / 确认 |
| 下键 | Esc，中断 / 取消 | Esc，中断 / 取消 |
| 旋钮按下 | Ctrl+R，搜索提示历史 | Ctrl+O，展开对话详情 |
| 逆时针 | Up，上一条提示历史 / 菜单项 | Up，上一条提示历史 / 菜单项 |
| 顺时针 | Down，下一条提示历史 / 菜单项 | Down，下一条提示历史 / 菜单项 |

以上为默认交互模式下的绑定，用户自定义键位或 Vim 模式可能改变实际行为。不会将 WorkBuddy 的 Ctrl+D 用于 CLI；该键在 CLI 中会退出或删除字符。

键位依据：[OpenAI 官方 Codex CLI 文档](https://learn.chatgpt.com/docs/developer-commands?surface=cli)、[Claude Code 官方交互文档](https://code.claude.com/docs/en/interactive-mode)。本机识别到 codex-cli 0.166.0、Claude Code 2.1.316。语音继续由现有 fcitx5-vinput 提交，不修改其微信 provider。

「添加 CLI 自动跟随」会添加缺失的两套方案并创建两条固定窗口标识规则，不覆盖已有同名方案或规则。添加方案时沿用当前语音键。默认方案保持原值；点击页面底部「保存到本机」后生效。

终端应用可承载多个不同 CLI，仅匹配「终端」本身无法可靠区分它们。推荐通过以下入口打开独立窗口：

- 设置页「Codex CLI 与 Claude Code」中的启动按钮。
- 应用菜单 `Codex CLI (VibeKey)` / `Claude Code (VibeKey)`。
- 在项目目录运行 `vibekey-codex` / `vibekey-claude`，支持透传 CLI 参数，工作目录保持为调用目录。

GNOME Terminal 的固定窗口 role 分别为 `vibekey-codex` / `vibekey-claude`；即使 CLI 改写终端标题，也不会丢失身份。已有普通终端可通过类别加专有标题手动绑定；专用入口不尝试接管已有会话或自动发送提示。启动 CLI 需要先安装相应工具及 GNOME Terminal。

## 实现与验证

前台窗口每 400 ms 在独立线程读取，不在 HID 轮询锁内执行外部命令。自动切换只更新运行时选择，不反复写配置；切换方案/层前取消排队动作、释放按住的键，并清理临时层。每次应用切换都以规则指定层为起点。同一窗口、同一规则内通过设备切层不会被轮询立即重置；切换到其他窗口后重新按规则选择。

手动点击「手动启用（关闭跟随）」会明确关闭自动跟随。编辑其他方案不会自动切换实际设备。被应用规则或默认方案引用的方案不能直接删除，需要先修改引用。

旧配置加载时自动补充关闭状态，默认方案设为原来的启用方案。当前用户已经启用两条 CLI 规则，并以原来的 Vinput 语音与音量方案作为默认回退。

[实机验证记录](auto-follow-live-test.json)：在本机打开两个短时 GNOME Terminal 测试窗口，分别观察 `codex-cli → acceptance → claude-code → acceptance` 自动切换；未启动 CLI 代理或发送模型请求。另验证终端改变标题后 role 保持不变。Python 测试覆盖匹配、规则顺序、迁移、缺失引用、释放按键、默认回退和不写磁盘；浏览器测试覆盖添加、保存、编辑规则、幂等设置、手动关闭跟随和响应式布局。
